# RWA Tokenization Protocol

A permissioned real-world asset tokenization protocol built with Solidity,
OpenZeppelin and Ethereum.

## Overview

This project explores the tokenization of real-world assets through
permissioned blockchain infrastructure.

The protocol is designed around:

- Asset registration
- Tokenized asset shares
- Investor whitelisting
- Transfer restrictions
- Role-based access control
- NAV updates
- Asset redemption
- Dividend distribution
- Asset freezing
- Emergency pause

## Technology

- Solidity
- Hardhat
- TypeScript
- OpenZeppelin Contracts
- Ethers.js
- Foundry
- Ethereum Sepolia
